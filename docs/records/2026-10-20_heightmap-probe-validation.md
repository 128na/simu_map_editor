# Simutrans実ローダーと頂点補正のプローブ検証

## 目的 / 発端

ADRのコミット後、画像形式、高さ変換、外周処理、斜面制約の検証を進めるよう依頼された。アプリの実装前に、一次ソースを読み取った仕様を、実コードを使って照合する。

## 実行対象と方法

対象コミットは `128na/simutrans` の `af90444e46dfd422bfdf80518aaa568659ec6b00`。ソースを変更せず、画像デコーダ群、height_map_loader、surfaceなどを外部ソースからビルドした。コンパイラはMSYS2 MinGW64 GCC 16.2.0。MAKEOBJでログ等の表示依存を避け、LTOで未使用のゲーム全体への依存を除去した。

- [ビルド手順](../../tools/validation/build-probe.ps1)
- [ネイティブプローブ](../../tools/validation/simutrans-probe.cc)
- [画像生成と照合](../../tools/validation/verify-heightmaps.mjs)
- [実行結果のサマリー](2026-10-20_heightmap-probe-results.json)

実行時にソースHEADと未コミット変更の有無を確認し、実行ファイル、プローブ、ビルドスクリプトのハッシュを照合する。外部ソースとビルド生成物はこのリポジトリに含めない。

画像の初期配置（+1、右端・下端複製）とcleanupの呼出順は、simworld.ccをもとに検証アダプターで再現した。近傍へ高さを伝播する `surface_t::raise_grid_to` は外部ソースの実関数を呼ぶ。期待値は同じ再帰処理の移植ではなく、各初期頂点からのチェビシェフ距離に応じた高さの上包絡で計算した。

## 分かったこと（事実）

15種類の画像それぞれに、変換4モード、高さ係数1/2、斜面上限1/2を適用した240ケースが通過した。標高上下限は-12/32に固定した。

| 検証対象 | 照合内容 |
| --- | --- |
| 全256灰階値 | 各モード・高さ係数で実loaderの返す標高と調査式が一致 |
| PNG | 8bit灰階、RGBのR成分、16bit灰階の上位8bitへの縮小 |
| BMP | 24bppの行パディングと上下方向、8bppの逆順パレット、RLE8のrun命令と行終端 |
| PPM | P6、最大値255、コメントを含むヘッダ、RGBのR成分 |
| 非対称・長方形 | 軸や上下方向の取り違え、W×Hサンプルから(W+1)×(H+1)頂点への配置 |
| 平地・孤立山・窪地・四隅 | +1と外周複製を含む補正後頂点を独立オラクルと全点比較 |
| 斜面 | 補正後の全タイル四隅のmax-minが1または2以内 |

逆引き表を構成できる到達標高も集計した。上下限-12/32ではLINEARとCLAMPは45レベルを表現できる一方、LEGACY_SMALLの係数1は22レベル（-12〜9）、LEGACY_LARGEの係数1は26レベル（-12〜13）に限られる。書出時に設定範囲全体を表現できると思い込まない判断を裏付けた。製品の書出機能はまだ実装していない。

## 再実行

Windows、Node.js、MSYS2 MinGW64のg++とlibpng、対象コミットのSimutransソースが必要。開発端末の既定パスを使う場合:

```sh
npm ci
npm run validate:heightmaps
npm run lint
```

別の場所にソースとコンパイラを用意した場合は、ビルドスクリプトの `-SimutransSource` と `-Compiler` にパスを渡し、Nodeの照合スクリプトには第1引数にソース、第2引数にコンパイラのbinディレクトリを渡す。生成画像と全ケースの結果は `.validation/` に作成する。CIの文書lintにこのWindowsローカル検証は含めない。

## 推測・未確認事項

- ゲーム全体での画像読み込みではない。simworldの初期化呼出順はアダプターで再現し、実際のkarte_t生成は実行していない。
- 水タイル生成、海岸の表示、湖・河川・砂浜、paksetの実画像との一致は未検証。
- 実ブラウザ、Three.js、GPUの速度・メモリ、1024×1024以上の実用性能は未測定。
- 盛土・掘削・平坦化・Undoのエディタ実装は存在せず、操作性と造成時の制約伝播は未検証。
- 今回の15画像でフォーマットの全分岐や不正ファイル耐性を保証しない。RLE8のabsolute/delta命令、透明PNGなどは未検証。
- 任意の標高上下限、上端のsint8境界、その他のゲーム版・paksetへの一般化はしていない。

既存のheadless実行環境とpaksetは見つかったが、標準CLI・設定・シナリオAPIからPNG/BMPを直接地形生成へ渡す経路は確認できなかった。既存exeの版も調査対象とは異なるソースに由来する。今回の結果を実機試験済みとは扱わない。

## 結果どうしたか

ローダーと頂点補正の再現検証を再実行可能なツールとして残した。描画・性能・造成操作に関するProposed ADRは、今回の成功だけではAcceptedへ変更しない。次は既知画像をゲーム全体へ読み込ませる照合と、ブラウザ描画・造成の試作で残る受け入れ条件を確認する。
