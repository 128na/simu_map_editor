# 読込時の正規化と補正警告の統合検証

## 目的 / 発端

[ADR-0010](../adr/0010-normalize-import-and-confirm-replacement.md)で決定した、画像読込時の補正と置換確認を検証用エディタへ反映した。

## 分かったこと（事実）

書出標高への量子化を適用した後、既存の8近傍斜面補正を編集用W×H sourceへ適用した。表示用の高さ+1と外周複製はsourceへ保存しない。置換確認で変更画素数、量子化の件数と範囲外・小数内訳、斜面補正件数を表示する。内訳は重複し得るため合算値とは扱わない。補正ありの読込は未保存、補正なしは保存済みとして扱う。

互換検証の対象はSimutrans Standardのaf90444e46dfd422bfdf80518aaa568659ec6b00。ローカル一次ソースsrc/simutrans/world/simworld.ccのcleanup_karteと、既存のnative probeを確認した。高さ変換やゲーム斜面アルゴリズム自体は変更していない。

単体58件、Chrome/Edge計48件が成功し、任意の重い検証12件をスキップした。lint・型検査・ビルドも成功した。元のnative decoded/grid比較を保持し、各形式・変換モード・高さ係数・最大斜面で、補正済みsourceがnative格子のW×H部分から高さオフセットを引いた値と一致すること、再読込時に追加補正が不要なことを確認した。非正方形・海面を含むfixtureでも確認した。

UIでは急斜面画像の補正警告、取消時の地形・履歴・未保存状態保持、補正後の書出BMPのnative格子一致、再読込時の補正なし表示を確認した。小数・範囲外はデコーダ後の通常標高には現れにくいため、独立した具体的期待値の単体テストで検証した。

## 推測・未確認事項

元画像の情報を完全保存する機能ではない。sourceを補正して外周を改めて複製するため、未補正画像から作った外周格子とは異なる場合がある。保証対象は補正後のsourceの再書出・再読込の一致である。ゲーム全体の湖・河川・砂浜生成は引き続き対象外とする。

## 結果どうしたか

検証用試作のファイル読込へ統合し、取消・解釈不能な入力では現在の地形を保持する経路を維持した。互換設定変更時の再正規化はこの変更には含めていない。
