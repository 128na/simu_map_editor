# ADR: 読込時に補正を明示し新規作成と読込の置換を確認する

> ステータス: Accepted (2026-10-20)

## 背景と問題

現在の試作では未正規化の画像を保持でき、最初の造成で広い範囲が正規化される場合がある。利用者は画像読込時に警告し、補正済みの状態をエディタへ反映すること、現在の地形の置換前に確認画面を出すことを選択した。

## 決定

対象プロファイルで読み込める画像について、書出可能な標高への量子化・範囲制約・自然地形の斜面条件を読込時に適用する。補正が発生する場合は警告し、何が何画素変わるかと補正後に編集することを示す。補正後の編集用sourceは引き続き+1前のW×H標高とし、表示用(W+1)×(H+1)格子を正本にしない。

新規作成とマップを開く操作には確認画面を挟み、現在の地形と履歴の置換を明示する。読込の補正警告は置換確認とまとめて提示できる。取消・選択取消・デコード失敗・資源不足では現在の地形と履歴を保持する。破損形式や未対応形式など解釈できない入力を、補正可能な地形と混同して黙って変換しない。

## 代替案と採用しない理由

最初の造成時だけ正規化すると、その造成と無関係な変更が混ざる。書出時だけ補正すると編集中の地形と成果物が変わる。黙って補正すると原画像との差が分からない。

## 影響と受け入れ条件

読込時の元の小数・不適合標高は保存用sourceに保持しない。元画像の全情報を往復保持する約束はしない。補正済みsourceからの再書出・再読込で外周複製と高さオフセット・補正後格子が一致することを検証する。急斜面・範囲外・小数・海面・非正方形を含め、警告と取消時の原本保持を検証してから実装済みとする。
