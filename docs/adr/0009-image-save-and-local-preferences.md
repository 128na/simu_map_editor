# ADR: 保存成果物をマップ画像としアプリ設定をlocalStorageへ保存する

> ステータス: Accepted (2026-10-20)

## 背景と問題

利用者は独自の編集再開ファイルを設けず、セーブデータをマップ画像と割り切る方針を選択した。バックエンドなしで、次回も使いたい小さなアプリ設定は保持したい。

## 決定

初期の保存成果物はマップ画像のみとし、独自プロジェクト形式は導入しない。標準書出形式はADR-0006のBMPを継承する。ブラシや表示などマップに依存しないアプリ設定をlocalStorageへ保存する。設定には版を付け、不正値や利用不可・容量不足の場合は初期値で動作できるようにする。

マップ標高、Undo履歴、小数の元値、選択や途中の操作を画像で復元できるとは扱わない。互換プロファイル・海面などマップの解釈に必要な値は画像に含まれず、読込時とゲーム側で明示確認する。最後に使ったプロファイルを初期候補として記憶する場合も、その画像の正しい設定として自動確定しない。

## 代替案と採用しない理由

独自の編集再開形式は設定や小数も保存できるが、形式の版管理と互換維持を初期実装へ追加するため見送る。画像と別設定ファイルの組を必須にする方式も利用者の保存方針に合わない。

## 影響

画像へ戻せない編集状態と互換設定の喪失は仕様上の制約として表示する。localStorageはブラウザ・origin内の便宜的な設定記憶で、別端末への持ち運びやバックアップではない。設定保持を実装済みとするADRではない。
