# ADR: 文書規約と検証をdocs-lint v1.1.0に統一する

> ステータス: Accepted (2026-10-19)

## 背景と問題

アプリ実装前の調査結果と設計案を保存し、後続開発で事実と提案を区別できる必要がある。ユーザーからdocs-lint v1.1.0による初期化が指定された。

## 決定

`docs-lint init new` の規約を採用し、調査・未実装設計は日付付きの不変記録、採用した判断の理由はADRへ置く。docs-lintはnpmの開発依存としてv1.1.0を指定し、ロックファイルとCIで同じ検証を実行する。

## 検討した代替案と却下理由

- 自由形式の設計書のみを維持する: 調査時点の事実と実装後の事実が混ざりやすい。
- CIで都度最新版を取得する: ローカルとCIの検証結果が依存更新だけで変わりうる。

## 影響・トレードオフ

記録の訂正は追記用の新記録で扱うため文書は増えるが、判断の経緯を保持できる。アプリ構成の採用は別途検証して判断する。
