# ADR: ChromeとEdgeの最新版を初期対応ブラウザとする

> ステータス: Accepted (2026-10-20)

## 背景と問題

利用者が正式対応範囲としてChrome・Edge最新版を選択した。互換設定を画像から復元できないことは既存の互換設計で確認している。

## 決定

初期の正式対応ブラウザはChromeとEdgeの最新安定版とする。古い版や他ブラウザの動作は保証範囲に含めず、検証では実ブラウザ版と描画環境を記録する。WebGL2が利用できない場合は明示する。

Simutrans互換範囲はADR-0005を継承し、対象Standardの版と変換モード・標高範囲・高さ係数・斜面条件・海面を明示したプロファイルとして扱う。任意のpakset・Extended・湖や河川や砂浜の追加生成までを一括して対応済みとはしない。プロファイルの既定値と一覧は対象版の一次ソースと実機照合結果に基づいて確定する。

## 代替案と影響

全ブラウザ・全ゲーム版を初期保証する方式は検証条件を広げすぎる。ブラウザ最新版への追随は依存更新と実ブラウザ回帰で確認する。対応ブラウザであることは、全端末で最大サイズを快適に扱えることを意味しない。
