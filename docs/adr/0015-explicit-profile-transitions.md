# ADR: 対象版付きの互換候補と設定変更時の補正を明示する

> ステータス: Accepted (2026-10-20)
> 由来: [統合検証記録](../records/2026-10-20_profiles-and-large-maps.md)

## 背景と問題

[ADR-0005](0005-explicit-simutrans-compatibility.md)で決めた標高上下限が画面では固定され、互換条件変更時にsourceを再補正していなかった。利用者は互換プロファイルの整備を大サイズ対応より先に進める方針を選択した。

## 決定

対象Standardのソース版と、変換モードに基づく設定候補を明示し、標高上下限を編集可能にする。候補はpaksetの値を推定したものとは扱わない。入力画像の標高を新しい候補で再解釈するのではなく、現在の編集用sourceを新しい条件へ正規化する。

補正内容を確認し、構造的な互換条件を変えた場合は履歴を破棄する。現在の地形が合法でも過去のUndo先が合法とは限らないため、現在の補正件数だけで履歴を保持する判断はしない。海面だけの変更では履歴を保持する。

画像に影響する変換条件を保存時の条件と比較し、再書出が必要な場合は未保存と表示する。海面の変更は画像の未保存状態を変えない。

## 検討した代替案と却下理由

元の画素を別プロファイルで再デコードすると、その後の造成との対応を失う。過去の履歴を全て再正規化する方式は、履歴が別の地形へ変化し、ストレージ読み出しも必要になるため採用しない。

## 影響・トレードオフ

構造設定変更後のUndoは使えないことを確認画面に示す。ゲームの設定上下限とエディタの対応範囲を区別し、上限127は補正用の余裕を残す現在の内部設計に合わせ125までとする。変更取消・不正値・確保失敗では元の地形・設定・履歴を保持する。
